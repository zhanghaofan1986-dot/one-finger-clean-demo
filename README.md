# 一指洗净 · One Finger Clean

竖屏趋势小 demo：用手指 / 鼠标拖着擦掉脏污蒙版，清到约 100% 播放完成音并通关；共 3 关不同脏点布局，可「模拟次日」让当前关略再脏。

纯前端、无外链资源；脏污与完成音均由 Canvas / Web Audio API 程序生成。

## 怎么打开

任选其一：

```bash
# 推荐：本地静态服务
cd /workspace/one-finger-clean
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

或直接双击 / 用浏览器打开 `index.html`（`file://` 亦可；部分浏览器对 `file://` 下 AudioContext 有限制，若无声音可改用上面的本地服务）。

手机：用同网电脑起 `http.server` 后访问 `http://<电脑局域网IP>:8765/`，竖屏体验最佳。

## 怎么玩 / 自测擦净反馈

1. 在中间「手机框」画布上按住拖动（触屏或鼠标均可）。
2. 顶部「清洁进度」会随擦除上升；脏污层用 `destination-out` 笔刷打穿。
3. 进度 ≥ 98% 时：
   - 播放 Web Audio 合成的短促通关音（无需外链音频文件）
   - 出现「擦干净啦！」遮罩
   - 「下一关」按钮可用（第 3 关通关后显示「已通关」）
4. 若进度不动：确认是否在画布区域内拖动；刷新页面重试。

## 关卡

| 关 | 名称     | 脏点布局           |
|----|----------|--------------------|
| 1  | 斑点泼洒 | 多处椭圆斑点 + 碎点 |
| 2  | 斜条污渍 | 斜向粗条 + 散点     |
| 3  | 角落堆积 | 四角径向堆积 + 中心 |

- **下一关**：通关后解锁，进入下一布局。
- **重擦本关**：完全重置当前关脏污。
- **模拟次日**：假时钟——在现有脏污上叠加一层半透明脏点（不完全重置），进度回落一点，可再擦。用于演示「过夜略再脏」。

## 技术要点（给改代码的人）

- 双 Canvas：底层干净表面 + 上层脏污；擦除用 `globalCompositeOperation = 'destination-out'`。
- 进度：抽样统计脏污层不透明像素，相对本关初始不透明量估算清洁比例。
- 指针：统一 `pointer` 事件，兼容 touch + mouse。
- 完成音：`AudioContext` 正弦上行短音阶，首次交互时 resume。
